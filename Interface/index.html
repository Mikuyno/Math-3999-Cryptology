📚 Project Overview

This independent study project focuses on cryptography and the mathematical foundations of cipher systems. Developed as part of Math 3999 at SUNY Oneonta under the mentorship of Professor Toke Knudsen, this cipher suite serves as an interactive educational tool for understanding classical and modern encryption techniques.

Course/Project Description

This independent study explores the mathematical foundations of cryptology, with a primary focus on Linear Algebra and Matrix Theory. The project transitions from simple modular arithmetic in Caesar and Vigenère ciphers to advanced linear transformations in polygraphic systems. A central component of the study is the implementation of the Hill Cipher, which utilizes matrix multiplication for encryption and matrix inversion over ℤ26. for decryption.

Learning Outcomes and Course Objectives

The goals of the independent study are as follows:

  • Application of Matrix Algebra: Perform and implement matrix operations (multiplication, inversion) within modular arithmetic (ℤn).
  • Linear Transformations: Analyze the security of ciphers by treating encryption as a linear mapping of vector spaces.
  • Modular Arithmetic & Number Theory: Master the Extended Euclidean Algorithm to find modular inverses, a necessity for Affine and Hill cipher decryption.
  • Computational Implementation: Develop software to solve systems of linear equations algorithmically to automate the cryptanalysis process.
