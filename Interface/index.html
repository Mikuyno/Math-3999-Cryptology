🔐 Cryptology Cipher Suite

SUNY Oneonta – Math 3999 Independent Study

Spring 2026

📚 Project Overview

This independent study project focuses on cryptography and the mathematical foundations of cipher systems. Developed as part of Math 3999 at SUNY Oneonta under the mentorship of Professor Toke Knudsen, this cipher suite serves as an interactive educational tool for understanding classical and modern encryption techniques.

Course/Project Description

This independent study will focus on cryptography. The student(s) will learn about field and work on coding examples. Special attention will be given to examples of linear algebra in cryptography.

Technologies & Languages

Frontend: HTML5, CSS3, JavaScript
Cryptography: JavaScript (Pure implementation, no external libraries)
Key Concepts: Modular Arithmetic, Linear Algebra, Matrix Operations

Learning Outcomes and Course Objectives

The goals of the independent study are as follows:

  • Gaining knowledge of cryptography
  • Gaining knowledge of coding examples in cryptography
  • Gaining knowledge of the role linear algebra plays in cryptography
  • Gaining experience with public speaking

Project Team

Collaborators: Bryce Davis, Klement Hysaj, Leonardo Martinez, Darin Mullen, David Scott
Professor: Toke Knudsen

🔐 Cipher Suite

Caesar Cipher c = (x + k) mod 26

Vigenère Cipher cᵢ = (xᵢ + kᵢ) mod 26

Affine Cipher c = (a·x + b) mod 26

Hill Cipher C = K·P mod 26

Block Cipher (Feistel) 3‑round, S‑box
